# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并在详情里展示聚会前快速复习卡片。

## 聚会复习队列

- 按本局人数生成复习队列，自动筛掉人数不合适的桌游。
- 队列会快照每个入选桌游的必复习卡片（容易忘的规则 + 常见争议）。
- 每张必复习卡片都要勾选并填写争议结论，任一项缺失时整次复习不能完成。
- 完成后本次快照冻结并进入历史；之后修改卡片只会体现在下次生成的新版本里，旧记录不变。
- 收藏中移除桌游时，包含它的未完成队列会停止，并在历史里记录停止原因。

## 文件结构

- `rules.js` —— 规则业务：桌游收藏、规则卡片、筛选逻辑
- `queue.js` —— 队列业务：复习队列的生成、进度、完成冻结与停止
- `storage.js` —— 本地存储：localStorage 读写
- `app.js` —— 界面渲染与事件绑定

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。
