# 桌游规则遗忘点卡片库

一个纯前端本地应用，用来管理桌游收藏中的规则遗忘点、常见争议、开局准备和计分提醒。支持按最近未玩、人数范围和复杂度筛选，并可按本局人数生成聚会前复习队列。

## 复习队列

- 输入本局人数生成队列，人数不合适的桌游会先被筛掉并列出原因。
- 每张必复习卡片必须勾选并填写争议结论，任一项缺失时整次不能完成，队列、统计和桌游数据保持原样。
- 完成后冻结本次快照，之后修改卡片只生成新版本，旧快照记录不变。
- 桌游从收藏移除时，引用它的未完成队列会停止并说明原因。

## 文件结构

- `rules.js` — 规则卡片领域逻辑（结构、版本、筛选、统计）
- `queue.js` — 复习队列状态（创建、勾选、结论、完成冻结、停止）
- `storage.js` — 本地存储读写与旧数据迁移
- `app.js` — 页面渲染与事件粘合

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。无外部依赖、无后端。
